Selected educational contributions

Videos & Technical Education

How’d You Code That is a technical education initiative created by Edward D. Clark to make software engineering, cloud computing, and application architecture more accessible through practical, example-driven instruction.

The selected recordings explore development techniques and architectural concepts, including AWS, web and mobile applications, and API integration. They reflect a commitment to sharing not only how technology works, but why particular engineering approaches are used.

These recordings span 2019–2023. Specific interfaces, product features, and implementation details may have changed since publication.
